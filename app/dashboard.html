Connect your Telegram account
  1. Sign in at my.telegram.org and open API development tools.
  2. Create an application (for example, title Telegram Monitor, short name linnmonitor). Add its credentials to your local .env:
    TELEGRAM_API_ID=your_api_id
TELEGRAM_API_HASH=your_api_hash
  3. In the project terminal, run:
    .\.venv\Scripts\python.exe .\sync_groups.py --login
    Enter your phone number, login code, and two-step verification password only in that terminal.
  4. Restart the monitor after changing .env. Return here and refresh the dashboard. Future updates use Sync account groups.
This sync stores group names and membership metadata. Automatic inbox monitoring is controlled separately; forwarding remains available. Keep your API hash, login codes, and local account session private; do not post them in chat.
